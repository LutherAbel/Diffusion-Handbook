TASK 001 已完成

DDPM、DDIM 與 RF baseline

Question

在同一個簡單 2D GMM、相同 NFE budget 下，RF、DDPM 和 deterministic DDIM 的 sampling quality 差多少？

Changed

Sampler：RF / DDPM / DDIM；NFE：1 / 5 / 20 / 100。

Fixed

同一個 2D 8-mode GMM（radius 4、component std .30）、exact target samples、initial noise、SWD projections。RF 與 diffusion 都訓練 3000 steps；diffusion 使用 T=300 scaled linear β schedule。

Metric

Generated samples 與 exact GMM samples 的 Sliced Wasserstein Distance (SWD)。越低越好。

Result

這個 baseline run 中，RF 在所有測試 NFE 都有最低 SWD。NFE 5、20、100 時 DDPM 低於 DDIM；NFE 1 時 DDPM 與 DDIM 相同。

Meaning

建立後續實驗的共同起點。這只能描述目前 controlled 2D setting，不能單靠它說 RF 一般而言比較好，也不能解釋差異來自哪個 mechanism。

T=300 是 computational shortcut：textbook 1e-4 → .02 beta range 以 1000/300 放大，讓 300-step process 的 terminal noise roughly 對齊 textbook 1000-step process。若之後改成 T=1000，beta 應回到 1e-4 → .02，不能保留 1000/300 multiplier。

TASK 004 已完成

Finite data、mode separation 與 replication

Question

Task 001 的 ranking 會不會依 training data size、抽到哪個 dataset、或 mode separation 而改變？

Changed
  • Initial finite-data test：training size 500 / 5000。
  • Mode separation：radius 1.5 / 6.0，關鍵條件再做 3-seed replication。
  • Data-size replication：500 / 1000 / 2500 / 5000，每個 size 用 3 個 independent datasets。
Fixed

2D 8-mode GMM、component std .30、3000 training steps、同一套 diffusion schedule；每個 replicate 內 RF / DDPM / DDIM 共用 dataset、target samples、initial noise 和 SWD projections。

Metric

SWD；replication 使用 mean SWD ± standard deviation。Data-size replication 共 144 raw results、48 aggregate results。

Result
  • Radius 6 的 single seed 曾在 NFE 20 / 100 出現 DDPM < RF；3-seed replication 後 crossing 消失，兩個 radii 都是 RF mean SWD 最低。
  • Data-size replication：NFE 1 四個 sizes 都是 RF 最低；500 / 1000 的高 NFE 仍是 RF；2500 的 NFE 100 與 5000 的 NFE 5 / 20 / 100 則是 DDPM 較低。
Meaning

沒有 monotonic data-size effect，也沒有一個 sampler 在所有 regime 都最好。最重要的是 single-seed crossing 可以消失，所以 sampler ranking 不能靠單次 training run 判斷。

Stochasticity：literature → η sweep → oracle score

Question

為什麼目前 GMM 裡 stochastic DDPM sampling 會比 deterministic DDIM 好？它是在修 learned-score model error，還是在修 finite-step discretization error？

Changed
  • Learned η sweep：η = 0, .25, .5, .75, 1，加上 sigma_hat。
  • Oracle control：把 learned network 換成 exact noised-GMM score，並用 5 個 independent seed blocks replication。
Fixed

同一 target GMM、true target samples protocol、NFE 1 / 5 / 20 / 100。Learned η sweep 固定同一 trained diffusion model；oracle side 只替換 score source。

Metric

Generated samples 對 true GMM samples 的 SWD；oracle 用 paired replicates 比較同一 seed block 內 setting 差異。

Result

Learned-model η sweep：NFE > 1 時，η 從 0 增加到 1，SWD 在 frozen run 中單調下降；NFE 1 全部相同。

TASK 007 5 replicates 已完成

Terminal prior mismatch

Question

Reverse sampling 通常從 N(0,I) 起跑，但 finite-time forward process 的真實 terminal distribution 是 q(x_T)。這個 mismatch 到底造成多少 sampling error？

Changed

β scale = 1 / 1.5 / 2 / 1000/300，terminal ᾱ_T 約 .0481 / .0104 / .00222 / .0000343；每個 schedule 比較 N(0,I) start 和 true q(x_T) start。DDIM / DDPM、NFE 1 / 5 / 20 / 100 都測，並跑 5 replicates。

Fixed

同一 2D 8-mode target 與 training / evaluation protocol。每個 beta-scale / replicate 內，兩種 start mode 使用同一 trained model 與相同 method / NFE comparison；不同 beta scale 會各自重新 train 對應 schedule 的 model。

Metric

gap = SWD[N(0,I) start] − SWD[q(x_T) start]。Positive gap 表示從 Gaussian prior 起跑比較差。

Result

主要 prediction 有得到支持：當 terminal distribution 還明顯不是 Gaussian（β scale 1，ᾱ_T≈.0481）時，從 N(0,I) 起跑有穩定 cost；當 β scale 增大、q(x_T) 越接近 N(0,I)，gap 逐漸失去一致方向並接近 0，DDPM 尤其明顯。

Sign consistency matters as much as the mean. At β scale 1, DDIM gap is positive in 5/5 replicates at every NFE; DDPM is positive in 5/5 at NFE 5 and 4/5 at NFE 20 / 100. At β scale 2 and 3.33, DDPM NFE>1 gaps are approximately zero and signs are mixed. The NFE=1 value at scale 3.33 is highly variable across replicates (mean +.0386, SD ≈ .0603), so it is not evidence of a stable residual mismatch.

Meaning

這支持 prior mismatch 的核心假設：terminal distribution 離 Gaussian 越遠，錯用 N(0,I) 當起點的代價越明顯；terminal 已非常接近 Gaussian 時，這個代價基本消失。

另外，在 β scale 1，增加 NFE 會把 gap 壓小，但沒有把它消掉：DDIM mean gap 從 NFE 5 的 +.0375 降到 NFE 100 的 +.0200；DDPM 從 +.0110 到 +.0087。這和「問題來自 initial distribution mismatch，而不只是 reverse discretization 太粗」的解釋一致。

限制：這不是每個 method / NFE 都嚴格 monotonic；只有 5 replicates，而且 DDIM 在較高 β scale 的 variability 比 DDPM 大。因此結論應寫成 qualitative support，而不是 universal law。
