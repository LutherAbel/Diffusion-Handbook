TASK 009 文獻部分完成

Ancestral sampling 為何可能有幫助

整理 DDPM 的 stochastic reverse sampling 和 DDIM deterministic sampling 之間的理論與實驗差異。

文獻的出發點

DDIM 的 η 將 η=0 的 deterministic DDIM 連到 η=1 的 DDPM。DDIM 論文的 CIFAR truncated sampling 結果中，η 增加時 FID 變差，這和本專案 2D GMM 的觀察方向相反。

本專案的假說

這個平滑 2D 問題可能不是由數值離散誤差主導，而是由 learned score 的近似誤差主導。每一步新增的隨機性可能減少已累積的偏移。這是推論，還不是已建立的因果結論。

接下來的證據

先做 oracle score control，再由 Task 010 的 η sweep 檢查中間 η 是否呈現有結構的變化。

TASK 009 Literature pass complete

Why ancestral sampling might help

Relate DDPM stochastic sampling to DDIM deterministic sampling.

Literature and project hypothesis

DDIM uses eta to interpolate from deterministic DDIM at zero to DDPM at one. The DDIM CIFAR truncated-sampling result moves in the opposite direction from this project's 2D GMM finding. One hypothesis is that learned-score approximation error, not discretization error, dominates here. This is an inference, not a causal conclusion.

Next evidence

Use an oracle-score control and the eta sweep in Task 010.

TASK 010 Results frozen, task record pending

Eta sweep

Hold the model and starting noise fixed, and vary only reverse-process stochasticity.

Design

eta=0 is DDIM and eta=1 should match DDPM. Compare eta 0, .25, .5, .75, 1, and sigma_hat.

Frozen result

For NFE above 1, SWD falls as eta increases in this controlled run. The eta 0 sample equals the DDIM reference, eta 1 matches the DDPM reference within numerical tolerance, and all settings agree at NFE 1.

Open question

Why sigma_hat does not collapse at low NFE remains unexplained. Oracle-score control is the next discriminating evidence.
