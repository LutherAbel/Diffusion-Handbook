Question

在同一個簡單 2D GMM、相同 NFE budget 下，RF、DDPM 和 deterministic DDIM 的 sampling quality 差多少？

Changed

Error-decomposition controls

Question

Does the stochasticity effect in the eta sweep come from learned-score model error or reverse-update discretization error? This task also measures the prior-mismatch cost of starting from N(0, I) instead of the true q(x_T).

Shared fact
